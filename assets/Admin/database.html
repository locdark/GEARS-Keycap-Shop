QUẢN LÝ KẾT NỐI CSDL MYSQL (NAVICAT CONNECTION)

Hỗ trợ kiểm tra Test Connection trước khi lưu, tự động cập nhật file cấu hình .env và đồng bộ dữ liệu vào MySQL XAMPP.

Cấu Hình Thông Số Kết Nối MySQL (Chuẩn Navicat Connection)
Lưu trữ: .env
Địa chỉ máy chủ cơ sở dữ liệu MySQL (Mặc định: 127.0.0.1)
Cổng dịch vụ MySQL XAMPP (Mặc định: 3306)
Tài khoản quản trị CSDL (XAMPP mặc định là: root)
Mật khẩu MySQL (XAMPP mặc định để trống)
Tên cơ sở dữ liệu đồ án (Nếu chưa có, hệ thống sẽ tự động tạo mới qua CREATE DATABASE)
# GEARS Keycap Shop - Cau hinh Co So Du Lieu DB_HOST=127.0.0.1 DB_PORT=3306 DB_USER=root DB_PASSWORD= DB_NAME=gears_keycap_shop SERVER_PORT=3333
Cơ Sở Dữ Liệu MySQL Hiện Tại: gears_keycap_shop
